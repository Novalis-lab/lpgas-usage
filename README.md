# プロパンガス使用量の目安（業務用・家庭用）

プロパンガス（LPガス）の1か月の使用量の目安（m³・kg）を出す Web ツールです。営業先でお客さんに画面を見せられるよう、結果を大きく表示します。

- 業務用：https://novalis-lab.github.io/lpgas-usage/
- 家庭用：https://novalis-lab.github.io/lpgas-usage/home/

ページ上部の「業務用／家庭用」で切り替えられます。novalis の秘密ページ（ガス屋向け）の「道具」欄にだけ置いています（トップページの一覧・サイトマップには載せていません）。

## できること

### 業務用
- コンロ：台数・1台の1日の使用時間・1台のガス消費量（kW。初期値18kWは仮の値なので銘板の値に書きかえる）
- 給湯器：号数（なし／16・20・24・32号）と、1日に実際にお湯を使う時間（分）
- 月の営業日数（初期値15日）、火力係数（初期値0.5、0.3〜1.0。コンロに掛ける）
- 結果：月間使用量（m³・kg）、少なめ・標準・多め（標準の ±25%）、機器ごとの内訳

確認用の例（喫茶店）：コンロ1台を1日2時間、給湯器20号を1日30分〜1時間（45分）、営業15日 → 少なめ 20.4／標準 27.3／多め 34.1 m³（およそ20〜35m³）

### 家庭用
- 世帯人数（1〜7人以上）、使う設備（給湯器・コンロ・床暖房・浴室乾燥機）、季節（年間・冬・春・夏・秋）
- 給湯器を使う家：家族人数別の平均（統計）× 季節の倍率。コンロを使わないときは計算式のコンロ分を引く
- 給湯器を使わない家：コンロだけを計算式で出す
- 床暖房・浴室乾燥機：銘板のkWを入れると、kW ÷ 27.9 × 時間 × 火力係数 × 日数 を足す（kWの初期値は空欄。信頼できる目安の数値が見つからなかったため）

## 計算のきまり

- 使用量（m³）＝ ガス消費量（kW）÷ 27.9 × 使用時間（時間）
  - プロパン1m³ ≈ 24,000kcal、1kW ＝ 860kcal/h → 1m³ ≈ 27.9kWh
- 給湯器の目安：16号 34.9kW、20号 43.6kW、24号 52.3kW、32号 69.2kW／家庭用コンロ 9kW
- 結果は小数第1位まで

## 出典

| 使っている数値 | 出典 |
|---|---|
| 重さの換算 1m³ ＝ 1.99kg（プロパン 0.502m³/kg） | 日本LPガス協会「プロパン、ブタン、ＬＰガスの立方メートルからキログラムへの換算係数について」（[山梨県の掲載PDF](https://www.pref.yamanashi.jp/documents/60408/lpgas_guidline_keisuu.pdf)） |
| 家族人数別の月平均（2人以下 6.5・3人 8.9・4人 11.3・5人 11.7・6人 12.0・7人以上 11.8 m³） | 石油情報センター「[平成18年度 プロパンガス消費実態調査](https://oil-info.ieej.or.jp/documents/data/20080303_2.pdf)」p.10 |
| 季節の倍率（全国の月別使用量 4月10.5〜3月10.8、月平均9.1） | 同じ調査の付属資料「都道府県別…月別1世帯当たり使用量」の全国の行 |

人数別の公的な統計は、2026年11月時点でこの平成18年度の調査が最新でした。新しい統計が出たら `lpgas.js` の `SURVEY_BY_PEOPLE` と `MONTHLY` を書きかえてください。
